# Contributing

IronLaw is an early-preview project. Contributions are welcome in the form of
issues, bug reports, and pull requests.

## Development

```sh
npm install
npm test
```

Node.js 20+. Each package is self-contained and has no runtime dependencies.

## Before opening a PR

- Add or update tests for the changed behavior.
- Run `npm test` from the repo root (runs every workspace).
- Keep changes minimal and scoped to one package where possible.
