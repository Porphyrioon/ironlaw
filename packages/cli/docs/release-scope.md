# 范围

正式包名：`@ironlaw/cli`。

## 来源

来自使用智能体编程框架做工程交付时的实践。针对长任务中的假完成、目标漂移和返工，将约束做成框架外的插件并开源。

## 效率工程

IronLaw 是效率工程组件之一。效率工程研究**非科研、非金融、非医疗、非教育**行业的效率范式：把长任务收成可验证的工程过程。

本仓库只包含 IronLaw。

## 范围以内

- 统一 CLI、统一协议、统一 sidecar
- 每套具备可验证 hooks 的智能体编程框架对应一块适配器
- 不具备 hooks 的框架仅提供可复制的 MCP 提示
- 事件、任务状态、证据账本，以及保守的危险操作规则

## 范围以外

- 新的编程工作台
- 多 Agent 席位或任务分派
- 将 `VERIFIED` 等同于使用体验
- 智能体编程框架自身的进程调度
